# Vinish-Portfolio

Modern executive portfolio for **Vinish Kumar** — Digital Marketing & SEO Specialist. Built with Next.js 16 (App Router), Tailwind CSS v4, and Framer Motion.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/` — Next.js App Router root layout and pages
- `components/` — Modular components (Hero, Certificates, SkillsProcess, Contact, Header)
- `public/images/` — High-resolution portfolio assets and credentials
